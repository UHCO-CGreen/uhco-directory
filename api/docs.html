Introduction

The UHCO Directory API provides programmatic read access to the University of Houston College of Optometry's people, organizations, and classification data. It is a JSON REST API served under:

https://<host>/api/v1/

All responses are JSON with UTF-8 encoding. All endpoints are read-only (GET). Attempting any other HTTP method returns 405 Method Not Allowed.

Base URL
http://127.0.0.1/api/v1/
Versioning

The current version is v1, reflected in the URL path. Breaking changes will increment the version number.

Authentication

All endpoints (except the root discovery endpoint) require a valid API token.

Supply the token using the Authorization header:

Authorization header (required)
Authorization: Bearer uhcs_<your-token>
Token query-string authentication is disabled. Use the Authorization header in all clients.
Quick Test Credential Generator

For quick API testing only: authenticate with Cougarnet (LDAP), then generate one token and one secret in a single request.

Restricted to only web services accounts. Each account is limited to one active quick-generated pair until revoked/deleted in Admin.

Default secret unlocks: Current-Student, Alumni.

Token scopes
ScopeAccess
readAll GET endpoints
writeReserved for future use
Secrets (Protected Data)

Certain records require both a valid token and a valid secret. Without a secret, those records are silently excluded from all results — the response will still succeed but will not include the protected people..

Protected by default

The following are excluded from every response unless a secret that unlocks them is supplied:

Protected dataUnlocked by secret granting…
Users with the Current-Student flagCurrent-Student
Users with the Alumni flagAlumni
Users in Academic Programs orgs
(OD Program, MS Program, PhD Program, Residency Program) 		Current-Student

Supply the secret alongside your token using request headers:

X-API-Secret header (required for protected data)
Authorization: Bearer uhcs_<your-token>
X-API-Secret: uhcs_sec_<your-secret>
If you filter by a protected flag or org (e.g. ?flag=Current-Student or ?org=OD+Program) without a valid secret, the response will return total: 0 and an empty data array rather than an error.

Response Headers

Every response (success or error) includes two identification headers:

HeaderValue
X-UHCO-Directory-Api-BaseThe scheme + host this request was actually served from, e.g. http://127.0.0.1/api/v1 or https://portal.opt.uh.edu/api/v1. Useful for confirming which environment answered when calling through a proxy or load balancer.
X-UHCO-Directory-AuthorizationEchoes back the bearer token you sent in the Authorization header (unvalidated — present even on 401 responses). Omitted if no Authorization: Bearer header was sent.
Browser clients calling cross-origin must read these via response.headers.get(...); they are exposed through Access-Control-Expose-Headers for allowed origins.

Errors

Errors return a JSON body with an error key and an appropriate HTTP status code.

{ "error": "User not found" }
StatusMeaning
400Bad request — invalid parameter (e.g. non-numeric ID)
401Missing, malformed, expired, or invalid token
403Token lacks required scope or request IP is not allowed
404Resource not found
405HTTP method not allowed
500Internal server error

Endpoints

GET /api/v1/people

Returns a paginated list of directory people. Supports full-text search across name and email fields. Each person row also includes a SHOWCASED_PUBLICATIONS array containing that user's public showcased publications.

Query Parameters
ParameterTypeDefaultDescription
searchstringnoneSearches first name, last name, preferred name, and primary email.
flagstringnoneFilter to users with this flag (exact flag name, e.g. Staff, Faculty-Fulltime). Protected flags require a secret.
orgstringnoneFilter to users in this organization (exact org name, e.g. Clinical Operations).
classintegernoneFilter by current graduation year. Requires access to Current-Student data.
gradyearintegernoneAlias for class when flag=Alumni or flag=Current-Student.
limitinteger50Max records to return. Maximum allowed: 500.
offsetinteger0Number of records to skip (for pagination).
returnstringjsonResponse format. Accepted values: json, xml.
secretstringnoneNot accepted as a query parameter. Send protected-data credentials in the X-API-Secret header instead.
Response
{
    "total": 3319,
    "limit": 50,
    "offset": 0,
    "data": [
        {
            "USERID": 1,
            "NAMES": { ... },
            "ORGANIZATIONS": [ ... ],
            "SHOWCASED_PUBLICATIONS": [
                {
                    "PUBLICATIONID": 501,
                    "CANONICALTITLE": "Example publication title",
                    "CANONICALAUTHORSTEXT": "Jane Doe; John Smith",
                    "PUBLICATIONYEAR": 2025,
                    "JOURNALORSOURCE": "Optometry and Vision Science",
                    "PRIMARYURL": "https://orcid.org/...",
                    "SOURCESERVICES": "ORCID"
                }
            ]
        }
    ]
}

Only publications explicitly marked as showcased are returned in SHOWCASED_PUBLICATIONS.

GET /api/v1/access

Returns all active, non-expired module permissions for a given identity user. Used by MyUHCO external modules to enforce permission-based access control. Callers should cache the response for ~10 minutes.

Authentication

Requires a valid API token with read scope and a valid API secret. Both must be present; missing or invalid either credential returns 401.

Query Parameters
ParameterTypeRequiredDescription
userIDintegerYesCanonical identity key for the user (from UHCO Identity).
Response — success (200)
{
  "userID": 128,
  "permissions": [
    "directory.view",
    "documents.upload",
    "documents.view",
    "portal.admin"
  ]
}
Response — user has no permissions (200)
{
  "userID": 999,
  "permissions": []
}

An unknown or permission-less user always returns 200 with an empty array — never 404.

Error Responses
StatusBodyCause
400{"error":"Invalid userID"}userID is missing, non-numeric, or < 1.
401{"error":"Unauthorized"}Token or secret is missing or invalid.
Permission String Format

Permissions are lowercase dot-separated strings: {module}.{action}. Each module defines its own action names.

ExampleMeaning
documents.viewCan view documents in the documents module
documents.uploadCan upload documents
directory.viewCan view the directory
portal.adminPortal-level admin access
Example Requests
GET /api/v1/access?userID=128
    Authorization: Bearer uhcs_...
    X-API-Secret: uhcs_sec_...
GET /api/v1/permission-roster

Returns all active, non-expired identity users who hold a given permission. The inverse of /access — given a permission key, resolve the full membership roster.

Authentication

Requires a valid API token with read scope and a valid API secret. Both must be present; missing or invalid either credential returns 401.

Query Parameters
ParameterTypeRequiredDescription
permissionstringYesDot-notation permission key to look up (e.g. MyUHCO.health-screening.screener).
Response — success (200)
{
  "permission": "MyUHCO.health-screening.screener",
  "total": 3,
  "users": [
    {
      "USERID": 42,
      "PRIMARYNAME": "Jane Doe",
      "PRIMARYEMAIL": "jdoe@uh.edu",
      "COUGARNETID": "jdoe"
    },
    {
      "USERID": 77,
      "PRIMARYNAME": "Alex Smith",
      "PRIMARYEMAIL": "asmith@uh.edu",
      "COUGARNETID": "asmith7"
    }
  ]
}
Response — permission exists but has no members (200)
{
  "permission": "MyUHCO.health-screening.screener",
  "total": 0,
  "users": []
}

An unknown permission key returns 200 with an empty array — never 404.

Response Fields
FieldTypeDescription
USERIDintegerCanonical identity key.
PRIMARYNAMEstringDisplay name — preferred alias first name + last name when set, otherwise first name + last name.
PRIMARYEMAILstringPrimary email address on file. Empty string if none.
COUGARNETIDstringCougarNet username from the external ID system. Empty string if not linked.
Error Responses
StatusBodyCause
400{"error":"Missing or invalid permission"}permission parameter is absent or empty.
401{"error":"Unauthorized"}Token or secret is missing or invalid.
