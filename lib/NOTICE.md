# Third-party jars

- `libphonenumber-9.0.34.jar` — Google's libphonenumber, used for international
  phone number parsing/validation/formatting. Apache License 2.0.
  https://github.com/google/libphonenumber

Loaded via `this.javaSettings.loadPaths` in `Application.cfc`. Self-contained to
this app; not installed into the shared ColdFusion server lib folder.
